### 💼 SkillSpark — AI Recruitment Platform

> *Production-grade platform transforming recruitment with AI-powered matching*

**📦 Repositories:** [Backend API](https://github.com/Anurag224132/Job-Recommendation-backend-spring-boot) • [Frontend App](https://github.com/Anurag224132/skill-spark-frontend-springboot-version) • [ML Service](https://github.com/Anurag224132/Job-Recommendation-ML)

**✨ Quantifiable Impact & Key Features:**

- 🚀 **40+ REST APIs** with role-based access for Students, Recruiters, and Admins
- ⚡ **88% Latency Reduction** on ML service (800ms → 95ms) using Redis job embedding caching and Gunicorn tuning (4 workers x 2 threads)
- 📉 **90% Fewer External Calls** to ML service, thanks to an intelligent caching strategy
- 🔐 **Secure Auth:** JWT with refresh-token rotation, Redis-backed sessions, and role-based access control
- 🤖 **Intelligent Matching:** Flask microservice using spaCy NER and TF-IDF cosine similarity (~78% relevance accuracy)
- 📊 **Production Observability:** Grafana + Spring Boot Actuator monitoring JVM, API p95/p99 latency, and DB pools
- 🛡️ **Resilience:** Spring Cloud Gateway with IP rate-limiting and a Resilience4j circuit breaker (fallback to keyword matching)
- 🎨 **Modern Frontend:** React Query, Recharts, Tailwind CSS for analytics dashboards

**Tech Stack:** `Spring Boot 3` `React.js` `PostgreSQL` `Redis` `Flask` `spaCy` `Docker` `Grafana` `Tailwind CSS`

### 💰 Currency Wallet — Multi-Currency Backend System

> *High-performance P2P payment system with real-time FX conversion*

**📦 Repository:** [GitHub Repo](https://github.com/Anurag224132/CurrencyExchangeProject)

**✨ Quantifiable Impact & Key Features:**

- 💸 **P2P Transfers** with real-time currency conversion (supports 10+ currencies)
- 📉 **90% Reduction in External API Calls** by caching exchange rates in Redis with a 5-minute TTL
- ⚡ **Improved p99 Latency** on conversion endpoints from ~400ms to ~45ms through aggressive caching
- 🔐 **Layered Security:** TOTP-based 2FA for high-value transfers (>₹10,000) on top of JWT auth. **Zero unauthorized transfers** during penetration testing
- 🏗️ **Robust Data Model:** Normalized PostgreSQL schema (wallets, transactions, audit_logs) with composite indexes
- 🚦 **High Performance:** Validated to handle **10,000+ TPS** with full transactional integrity using ACID compliance
- 📝 **Complete Audit Trail:** Every transaction logged with immutable audit records

**Tech Stack:** `Spring Boot` `Redis` `PostgreSQL` `Docker` `TOTP (Google Authenticator)` `Maven`
